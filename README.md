# Finite-Sample Information Allocation for Self-Supervised Restoration under Mixed Noise

This repository contains the code and compact reference results accompanying
the paper. It covers the mixed-noise self-supervised constructions, the
finite-sample Gaussian calculations, label-free allocation selection, the
Gamma--Poisson thinning comparison, the seed-fusion analysis, and the reported
natural-image DnCNN experiment.

## Repository layout

- `allocation/`: mixed-noise constructions, scalar risk calculations,
  allocation experiments, selection rules, supervised references, and
  independent numerical checks.
- `natural_mixed/`: the DIV2K-to-B100/Set14/Urban100 DnCNN experiment,
  exact DIV2K preprocessing, aggregation, verification, and figure generation.
- `reference_results/`: compact CSV/JSON records from the reported runs. Model
  checkpoints, benchmark images, caches, and large per-image archives are not
  redistributed.
- `NOTATION.md`: correspondence between the paper notation and retained
  historical result-field names.
- `REPRODUCIBILITY.md`: end-to-end data preparation, execution, artifact, and
  verification instructions.

## Environment

Python 3.10 or later is recommended. Create an isolated environment and run:

```bash
python -m pip install -r requirements.txt
```

For the version-pinned reproduction environment, use
`requirements-reproduction.txt`. The recorded GPU environment and precise data
protocol are documented in `REPRODUCIBILITY.md`.

The numerical scripts use NumPy, SciPy, pandas, Matplotlib, Pillow, and
PyTorch. CUDA is required only for the full neural-network experiments.

## Quick checks

From the repository root:

```bash
python -m compileall -q allocation natural_mixed
python allocation/verify_constructions.py --output construction_check.json
python allocation/verify_seed_fusion.py --result-dir reference_results/seed_fusion_20261015
python natural_mixed/verify_natural_mixed.py --aggregate-only \
  --root reference_results/natural_mixed_base_20261015/results
```

The compact natural-image check verifies the released protocols, candidate
tables, locked validation selections, test summaries, and cross-seed
aggregates. The full check additionally requires the checkpoints and per-image
arrays generated by `run_mixed_dncnn.py`.

## Controlled mixed-noise experiment

The main controlled experiment uses the fixed candidate grid
`0.25, 0.5, 1, 2, 4, 8` and the protocol encoded by the command defaults:

```bash
python allocation/run_allocation.py --out output/allocation_main
python allocation/run_corrected_allocation.py --run output/allocation_main
python allocation/run_gp_thinning_comparison.py \
  --source output/allocation_main --out output/gp_thinning
python allocation/run_seed_fusion.py \
  --run output/allocation_main --out output/seed_fusion
```

Validation statistics are computed before independent test data are generated.
Exact seeds and run-level settings are recorded in the corresponding protocol
and selection files under `reference_results/`.

## Natural-image experiment

Prepare the exact DIV2K crop cache and local copies of B100, Set14, and
Urban100:

```bash
python natural_mixed/prepare_div2k_cache.py \
  --div2k-root /path/to/DIV2K_train_HR \
  --output data/div2k_cache.pt \
  --manifest data/div2k_cache_manifest.json
```

Then run one process for each seed:

```bash
python natural_mixed/run_mixed_dncnn.py \
  --seed 0 --device cuda:0 \
  --out output/natural_mixed/base_seed0 \
  --data-cache /path/to/div2k_cache.pt \
  --benchmark-root /path/to/benchmarks
```

Repeat with seeds `1` and `2`, changing the output directory for each run.
Each seed trains 18 self-supervised candidates: three mixed-noise models and
six allocation values. The script saves the validation selections before it
loads B100, Set14, or Urban100.

To aggregate the three completed runs, use:

```bash
python natural_mixed/summarize_formal.py output/natural_mixed
```

Dataset files are not included. They should be obtained from their original
sources and placed outside the repository. See `REPRODUCIBILITY.md` for the
complete directory layout, recorded environment, artifact archive, and audit
commands.
